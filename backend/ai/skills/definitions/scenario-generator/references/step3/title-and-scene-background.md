# 标题与场景背景写作规范

## 一、场景标题（title）规范

### 1.1 长度

- **限制**：≤ 20 个中文字符
- **推荐**：10-15 字
- **示例**：
  - ✅ "三甲心内科新品介绍对练"
  - ✅ "PCI 术后抗血小板讨论"
  - ❌ "张主任心内科心血通新品介绍场景"（24 字，超长）
  - ❌ "对练"（2 字，过短）

### 1.2 禁止内容

| 禁止项 | 原因 | 示例 |
|---|---|---|
| **姓氏** | 隐私保护 | ❌ "张主任对练" → ✅ "心内科主任对练" |
| **祈使句** | 标题应陈述性 | ❌ "请完成新品介绍" → ✅ "新品介绍对练" |
| **疑问句** | 标题不应提问 | ❌ "如何介绍新品？" → ✅ "新品介绍对练" |
| **具体剂量** | 合规要求 | ❌ "10mg 心血通对练" → ✅ "心血通对练" |
| **内部 ID** | 保密红线 | ❌ "场景 1234" → ✅ "心内科对练" |
| **感叹号** | 中性陈述 | ❌ "新品对练！" → ✅ "新品对练" |

### 1.3 推荐结构

`[医院级别][科室][主题]对练` 或 `[科室][品种][主题]`

示例：
- "三甲心内科新品介绍对练"
- "心内科心血通安全性讨论"
- "PCI 术后用药异议处理"

### 1.4 生成逻辑

LLM 应基于 `draft.collection` 中的科室、品种、推广场景主题组合生成，避免使用医生姓名。

## 二、场景背景（sceneBackground）规范

### 2.1 长度

- **限制**：150-300 个中文字符
- **推荐**：200 字左右
- **过短**：信息不足，影响对练代入感
- **过长**：用户难以快速阅读

### 2.2 视角

- **必须**：第三人称叙述
- **禁止**：第一人称（"我/我们"）或第二人称（"你/您"）
- **示例**：
  - ✅ "本场景设定在某三甲医院心内科，客户为主任医师，关注 PCI 术后安全性..."
  - ❌ "您将拜访一位心内科主任..."（第二人称）
  - ❌ "我是一位心内科主任..."（第一人称）

### 2.3 内容要素

| 要素 | 是否必含 | 示例 |
|---|---|---|
| 客户身份 | ✅ | "某三甲医院心内科主任医师" |
| 客户关注点 | ✅ | "关注 PCI 术后抗血小板治疗的长期安全性" |
| 客户顾虑 | 推荐 | "对新型 P2Y12 抑制剂的出血风险有顾虑" |
| 拜访目标 | ✅ | "本次拜访目标是介绍产品 X 的长期安全性数据" |
| 时间约束 | 推荐 | "客户时间紧张，仅有 10 分钟" |
| 历史背景 | 推荐 | "此前已拜访 2 次，建立初步关系" |
| 具体剂量 | ❌ | 不出现 "10mg" "5mg" 等 |
| 具体姓氏 | ❌ | 不出现 "张主任" "李医生" |
| 内部 ID | ❌ | 不出现 "doctor_id=123" |

### 2.4 同源性保证

`sceneBackground` 与落库字段 `repBriefing`（即 `PracticeScenario.description`）必须**完全一致**。

实现方式：
- LLM 生成 sceneBackground 后，由 `merge_scene_draft` 工具写入 `draft.title_bg.scene_background`
- `create_scene_record` 工具调用 `training_service.create_scene_from_draft` 时，直接将 `draft.title_bg.scene_background` 写入 `PracticeScenario.description`
- 禁止 LLM 在 merge 后修改 sceneBackground 内容

### 2.5 生成示例

**输入**：
```json
{
  "collection": {
    "doctor_persona": "心内科主任医师，关注 PCI 术后安全性，对新型 P2Y12 抑制剂有兴趣但担心出血风险",
    "drug_name": "心血通",
    "best_practice_points": ["开场基于 ESC 指南", "呈现 12 个月随访数据", "出血风险管理策略"]
  }
}
```

**输出（sceneBackground）**：
```
本场景设定在某三甲医院心内科，客户为主任医师，擅长冠心病介入治疗，近期关注 PCI 术后抗血小板治疗的长期安全性。客户对新型 P2Y12 抑制剂有兴趣，但担心出血风险。本次拜访目标为介绍心血通的长期安全性数据，推动进入处方流程。客户时间紧张，门诊间隙仅有 10 分钟交流时间，需简明扼要呈现核心数据。
```

**字数**：约 150 字，符合规范。

## 三、生成失败降级

| 失败场景 | 降级方案 |
|---|---|
| LLM 不可用（provider=mock） | 标题模板："{科室}{品种}对练"；背景模板："本场景为{科室}{品种}的{主题}对练场景。" |
| LLM 输出含姓氏 | 自动替换为"主任/医生"，重新生成 |
| LLM 输出超长 | 截取前 20 字（标题）/ 300 字（背景） |
| LLM 输出为空 | 降级到模板生成 |
